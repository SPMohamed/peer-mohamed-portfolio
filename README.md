## 🌐 GitHub Pages Deployment Guide

This project includes a turnkey GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys your site whenever changes are pushed to `main`.

### Step 1: Initialize Git and Commit
```bash
git init
git add .
git commit -m "Initial commit: Premium IT Support Engineer Portfolio for S. Peer Mohamed"
```

### Step 2: Create Repository on GitHub
1. Go to [GitHub.com/new](https://github.com/new)
2. Set **Repository name** to: `peer-mohamed-portfolio`
3. Set visibility to **Public**
4. Click **Create repository**

### Step 3: Link & Push to GitHub
```bash
git branch -M main
git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/peer-mohamed-portfolio.git
git push -u origin main
```

### Step 4: Enable GitHub Pages in Repository Settings
1. On GitHub, navigate to your repository **Settings** tab.
2. In the left sidebar under *Code and automation*, click **Pages**.
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. The workflow will automatically run and publish your website at:
   `https://<YOUR-GITHUB-USERNAME>.github.io/peer-mohamed-portfolio/`
